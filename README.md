🍎 AIoT-Based Food Spoilage Detection System

An AIoT-enabled Machine Learning system to predict food spoilage using environmental parameters such as temperature, humidity, and gas levels. The project demonstrates an end-to-end ML pipeline including data preprocessing, model training, backend integration, and visualization.

🧠 Tech Stack

Language: Python
ML: Scikit-learn, Pandas, NumPy
Visualization: Power BI
Backend: Flask
Database: MongoDB
Tools: Git, GitHub, Kaggle

🏗️ Architecture

Data collection and preprocessing
Feature analysis and model training
Backend integration for predictions
User input via web interface (manual & CSV)
Visualization through dashboards

🔄 Workflow

Input environmental parameters
Data validation and preprocessing
Spoilage prediction using trained model
Storage of results
Dashboard visualization
